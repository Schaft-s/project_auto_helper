# ADR: Mechanics SE как третий tool + golden-набор

Статус: принято для MVP без SFT/КСО.
Дата: 2026-10-24.

## Контекст

Нужен источник «как делают люди», отдельно от NHTSA и от сборочного специалиста. Корпус КСО недоступен. Нужны проверяемые аргументы, почему три tool и одна модель Flash, а не смесь всех текстов в одном RAG.

## Решение

1. Mechanics Stack Exchange (shard H4, CC BY-SA) индексируется отдельно (`data/mechanics/qa.jsonl`) и вызывается только через `search_discussions`.
2. Сборочный specialist по-прежнему видит только демо-документы фиксаторов/панелей. Форумные ответы в его контекст не попадают.
3. Оркестратор и specialist — одна OpenRouter-модель `deepseek/v4.1-flash`, разные промпты. Нет дообучения.
4. Golden JSONL (`evaluation/golden.jsonl`) фиксирует маршрут, tool, source_id и запрещённые формулировки. Offline-кейс проверяет clarify без сети; live-кейсы требуют MCP + OpenRouter.

## Последствия

- Архитектура трёх источников проверяется тестом, а не слайдом.
- Тексты форума нельзя выдавать как сервисную карту: в карточке ответа есть ограничения CC BY-SA и URL.
- Лексический RAG, не pgvector; отбор ~400 Q&A, не весь shard.
