Что умеет система

Не «чат ради чата», а маршрутизатор по трём источникам правды плюс диалоговый контекст.

Отзывы и жалобы NHTSA

По марке / модели / году находит отзывные кампании и жалобы владельцев через настоящий MCP. Явно говорит, что база — рынок США.

Опыт механиков и учебники

Hybrid RAG: Mechanics Stack Exchange + BCcampus. В ответе — ссылка на источник, не пересказ «как официальная карта».

Сборка и проверки

Клипсы, панели, фары, чек-лист после установки. Specialist — отдельный LLM-вызов с отдельным промптом внутри tool.

Живой диалог

Машину берёт из текста. Помнит историю. Меняет машину без путаницы. На «спасибо» не гоняет поиск заново.

Режимы owner / mechanic

/mode меняет язык и подробность. Ограничения безопасности (SRS/HV) не снимаются.

Честные отказы

Нет данных NHTSA по Chery/Lada — не подставляет Civic. Airbag — caution, без пошаговой «инструкции».

Функционал бота подробно

1

Свободный текст вместо анкеты

Марка, модель и год извлекаются из реплик. Отдельной команды /car нет — меньше трения.

2

Три tool под разными задачами

NHTSA · discussions · workshop. Оркестратор выбирает маршрут; combined — когда нужны два источника.

3

История диалога

Follow-up «в пробке», «на этой машине», смена темы с симптома на сборку — без потери машины.

4

Безопасность и политика

SRS/высоковольт — caution. Нет VIN-проверки, нет диагноза, нет подмены модели.

Лимиты: rate-limit, concurrency, таймауты на router / specialist / MCP — чтобы демо не «висело» бесконечно.

Архитектура

Один оркестратор, три инструмента. Specialist — не второй чат, а внутренний вызов внутри workshop_consult.

Пользователь Telegram → aiogram bot → Orchestrator → OpenRouter
vehicle_safety_lookup → MCP server → NHTSA API
search_discussions → Qdrant hybrid → Mechanics SE + BCcampus
workshop_consult → Specialist (отдельный промпт) + demo corpus клипсов/панелей

Оркестратор

DeepSeek Flash, tool-calling, итог в Telegram HTML. На «спасибо» — short-circuit без tools.

Specialist

Сейчас — специализированная модель с отдельным промптом. Планируется заменить на дообученную модель специалиста по сборке.

Политика

Opaque workshop payload: шаги specialist не переписываются оркестратором «от себя».

MCP-интеграция

Критерий курса закрыт по-настоящему: протокол MCP, не «REST под видом интеграции».

MCP toolЧто даёт
nhtsa_search_recallsОтзывные кампании
nhtsa_search_complaintsЖалобы владельцев
nhtsa_lookup_vehiclesСправочник моделей

Почему это важно

  • Свой минимальный MCP-сервер на Python SDK
  • Клиент: initialize / tools/call по streamable HTTP
  • Фасад vehicle_safety_lookup не ходит в REST напрямую
  • Chery/Lada не подменяются «похожей» US-моделью
  • Поднимается в Docker Compose вместе с Qdrant

Откуда знания

NHTSA

Официальные recalls и complaints, рынок США. Через MCP — живые ответы API.

Mechanics Stack Exchange

CC BY-SA. Hybrid search: dense + BM25 в Qdrant. В ответе URL, не полная перепечатка.

BCcampus / Trades Access

Учебные тексты CC BY 4.0 (мультиметр и др.). Отдельная коллекция tech_manuals.

Workshop corpus

Демо-документы по клипсам/панелям для specialist. Без применимого куска — general / EASSUME, без выдуманной OEM-карты.

Почему не один большой RAG на всё

NHTSA, форум и сборка — разные типы правды. Разделение tool’ами проверяется тестами маршрутизации: отзыв не должен уехать в workshop, а клипса — в NHTSA.
